# /lhg-user-growth:experiment —— 实验卡

用户输入在 `$ARGUMENTS` 中：一种是新想法（生成实验卡），一种是 `E1 复盘` / `复盘 E2`（填写复盘）。

## 模式 A：生成实验卡

### 实验卡模板（逐项填，不许空）
```markdown
## 实验 E<n>：<一句话标题>
- **杠杆环节**：获客/激活/留存/变现/推荐（只选 1 个）
- **假设**：如果<动作>，那么<指标>会从<基线>变为<目标>，因为<原因>。
- **动作**：谁、在哪、做什么（具体到可执行，如"在注册后第 2 步加 1 个 30 秒产品视频"）
- **成功指标**：<指标名>（口径：<怎么算>），基线 <X> → 目标 <Y>
- **周期**：<N> 天（开始日期 - 结束日期）
- **负责人**：<名字>
- **ICE 评分**：I<n>/C<n>/E<n> = <总分>
- **复盘**：（跑完再填）实际结果 / 结论：成立|证伪|无法判断 / 下一步
```

### 填写纪律
1. 假设句式必须是"如果…那么…因为…"：写不出"因为"说明假设是拍脑袋，打回去重想。
2. 成功指标只许 1 个主指标（可加 1~2 个护栏指标，如"不降低注册转化率"）：3 个主指标 = 没想清楚。
3. 基线没有数据就写"无基线，先跑 7 天测基线"：不许编基线数字。
4. 写完跑校验：`python3 ${CLAUDE_PLUGIN_ROOT}/scripts/audit/experiment_audit.py --target <实验卡文件>`，blocker 清零再交付。

## 模式 B：复盘（`E<n> 复盘`）

加载 skill `lhg-ug-review`，按复盘模板执行：
1. 问用户要实际结果（指标前后数字、周期是否跑满、有无异常）。
2. 下结论三选一：**成立**（达到目标且归因可信）/ **证伪**（没达到或归因不成立）/ **无法判断**（数据不足/被干扰，写清原因）。
3. 给下一步：成立→放大（扩大流量/固化为功能）；证伪→换杠杆或换假设；无法判断→补实验（写清补什么）。
4. 需要统计显著性背书 → 转 `lhg-growth-lab` 的 `/growth-lab:ab-significance`。

## 硬规则
- 实验卡缺假设/动作/指标/周期任一项 = 半成品，不许说"写好了"。
- 复盘结论不许写"效果不错"这种模糊话：必须三选一 + 数字。
- 一次只复盘 1 个实验：多个实验一起复盘会互相甩锅。
